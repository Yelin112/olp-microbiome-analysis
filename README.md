# OLP Microbiome 分析工作目录

OLP（口腔扁平苔藓）微生物组研究相关的数据分析工作目录。

项目导航、目录结构、命名约定、工作模式、多机协作、主题/配色系统等完整说明见
**[CLAUDE.md](CLAUDE.md)**（本仓库唯一维护的导航文档，避免和本文件重复漂移）。

通用 R 工具库（主题系统、配色系统、可复用分析函数）在独立仓库
**[r-pub-toolkit](https://github.com/Yelin112/r-pub-toolkit)**，不在本仓库内。

## 版本控制

- R/Python 脚本纳入 Git 版本控制
- 输出文件（PDF/PNG/SVG）不纳入版本控制
- 原始数据不纳入版本控制，定期备份
- 测序原始数据在服务器上分析，不在本地存放
