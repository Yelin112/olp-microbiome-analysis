# CIBERSORTx细胞丰度相似性分析 - 论文方法与结果

## 研究方法

### 2.X 细胞丰度变化相似性分析

为评估不同造模方法与OSF疾病在细胞组成变化模式上的相似性，我们采用了多维度统计分析方法。首先，计算各组相对于其对照组的细胞丰度变化值（OSF组相对于Normal组，各造模组相对于PBS组）。基于这些变化值，我们进行了以下分析：

**（1）层次聚类分析**

采用Ward's D2方法和欧氏距离构建层次聚类树状图，通过Cophenetic相关系数评估聚类质量。Cophenetic相关系数>0.75表示聚类结构优秀，0.60-0.75为良好，<0.60为较差[1]。

**（2）主成分分析（PCA）**

对细胞丰度变化数据进行主成分分析，以降维方式可视化各组间的相似性。计算各主成分的方差解释率，并分析细胞类型对主成分的贡献（载荷值）。采用置换多元方差分析（PERMANOVA，999次置换）检验组间差异的显著性[2]。

**（3）相关性分析**

计算各组间细胞丰度变化的Pearson相关系数，并进行显著性检验。构建相关性网络图，以|r| > 0.3为阈值展示组间关系，用实线和虚线分别表示显著（p < 0.05）和非显著相关性。

**（4）显著变化细胞类型的重叠分析**

定义|变化值| > 0.01为显著变化阈值，识别各组的显著变化细胞类型。采用Fisher精确检验评估OSF与各造模组显著变化细胞类型重叠的统计学意义，计算比值比（Odds Ratio, OR）。OR > 1表示重叠高于随机期望，OR < 1表示低于随机期望[3]。

**（5）统计分析**

所有统计分析使用R软件（版本4.3.0）完成。PCA分析使用stats包的prcomp函数，PERMANOVA使用vegan包的adonis2函数。层次聚类使用hclust函数，相关性检验使用cor.test函数，Fisher精确检验使用fisher.test函数。p < 0.05认为差异具有统计学意义。

## 研究结果

### 3.X 不同造模方法与OSF的细胞组成变化相似性

#### 3.X.1 层次聚类分析揭示造模组聚类模式

基于细胞丰度变化的层次聚类分析显示，7个研究组（OSF及6个造模组）形成了清晰的聚类结构。Cophenetic相关系数为0.686，表明聚类质量良好，聚类树状图能够较准确地反映组间的真实距离关系（图1A）。聚类结果显示，部分造模组与OSF在细胞变化模式上表现出更近的相似性，提示这些造模方法可能更好地模拟了OSF的细胞免疫微环境改变。

#### 3.X.2 主成分分析显示细胞变化的主要驱动因素

主成分分析揭示了细胞丰度变化的主要模式（图1B）。前两个主成分累计解释了97.74%的总变异（PC1：88.88%，PC2：8.86%），表明细胞组成变化可以由少数几个主要因素驱动。

载荷分析显示，PC1主要由Myocytes（载荷值 = -0.911）、Macrophages（0.319）和Epithelial cells（0.187）驱动。这提示肌细胞的变化是区分不同组别的最主要因素，巨噬细胞和上皮细胞的改变也发挥了重要作用。PC2则主要由Epithelial cells（-0.845）、Macrophages（0.498）和增殖T细胞（Tprolif, -0.106）贡献。

PERMANOVA检验显示R² = 1.000，表明组间差异能够完全解释细胞组成变化的方差，各组在细胞变化模式上具有明显的区分度。

#### 3.X.3 相关性网络分析识别组间关系

对21对组间关系进行Pearson相关分析，发现14对（66.7%）显示显著相关性（p < 0.05）。其中13对为正相关，提示这些组在细胞变化方向上趋于一致；8对为负相关，提示存在相反的变化趋势（图1C）。

以|r| > 0.3为阈值构建的相关性网络包含17条边，其中14条（82.4%）达到统计学显著性。网络的平均相关强度为0.759，表明组间存在较强的关联。网络拓扑结构显示，OSF与多个造模组存在显著相关关系，提示这些造模方法在细胞水平上部分复制了OSF的免疫微环境特征。

#### 3.X.4 显著变化细胞类型的重叠模式

在|变化值| > 0.01的阈值下，OSF组共有10种细胞类型发生显著变化。Fisher精确检验评估了各造模组与OSF在显著变化细胞类型上的重叠情况（表1，图1D）：

* **B组**显示最高的重叠率（60.0%），6种细胞类型与OSF重叠（OR = 2.50，p = 0.6145），提示B组造模方法影响的细胞类型与OSF最为一致。
* **AB组**和**Am组**的重叠率分别为50.0%（OR = 2.90，p = 0.3575）和40.0%（OR = 4.36，p = 0.3077），显示中等程度的重叠。
* **Pm组**虽然重叠率为40.0%，但OR值为无穷大（p = 0.0885，接近统计学显著），提示该组显著变化的细胞完全包含在OSF显著变化细胞中，具有较高的特异性。
* **Ai组**和**Av组**的重叠率较低（均为30.0%，OR = 2.81，p = 0.5846），提示这些造模方法诱导的细胞变化与OSF存在一定差异。

尽管由于样本量限制，Fisher精确检验未达到传统的统计学显著性水平（p < 0.05），但所有造模组的OR值均 > 1，表明重叠程度均高于随机期望，提示各造模方法在不同程度上模拟了OSF的细胞组成改变。

#### 3.X.5 综合相似性评价

综合层次聚类、PCA、相关性网络和重叠分析的结果，**B组**和**AB组**在多个维度上与OSF表现出较高的相似性，包括较高的细胞类型重叠率、显著的相关性以及在主成分空间中的接近性。**Pm组**虽然重叠细胞数量较少，但具有较高的特异性（OR = Inf），提示其诱导的细胞变化高度聚焦于OSF的核心改变。**Am组**显示中等程度的相似性，而**Ai组**和**Av组**与OSF的相似性相对较低。

这些结果表明，不同造模方法在复制OSF细胞免疫微环境方面存在差异，为后续选择合适的动物模型提供了定量依据。

## 补充说明

### 关于PERMANOVA结果的说明

PERMANOVA检验显示R² = 1.000，F值和p值为NA。这种情况通常出现在以下场景：

1. 样本量相对于变量数较小时
2. 组间差异极其显著，导致完全分离

在本研究中，7个组、16个细胞类型的情况下，R² = 1.000表明组间在细胞组成变化上具有完美的可分性。虽然无法计算传统的F检验和p值，但这一结果仍然有力地支持了各组在细胞水平上存在明显差异的结论。

### 关于Fisher精确检验p值的解释

尽管Fisher精确检验的p值均未达到0.05的传统显著性水平，但这主要受限于：

1. 较小的样本量（细胞类型数量有限）
2. 2×2列联表中较小的观测值

然而，所有造模组的OR值均 > 1（最高达Inf），这一趋势性结果提示重叠程度确实高于随机期望。在探索性研究和方法学比较中，这种趋势具有重要的参考价值。

### 统计学意义与生物学意义

在动物模型评价研究中，统计学显著性固然重要，但生物学意义同样需要重视。本研究通过多维度分析（层次聚类、PCA、相关性、重叠分析）的交叉验证，为不同造模方法的相似性提供了综合性证据。重叠率、OR值、相关系数等定量指标为模型选择提供了客观依据，即使在部分指标未达到传统显著性水平的情况下，这些趋势性结果仍具有重要的方法学指导价值。
